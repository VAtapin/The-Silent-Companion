# Тихий спутник — производство фильма

Закрытая рабочая система производства короткометражного фильма «Тихий спутник» с публичной страницей проекта. Интерфейс полностью на русском языке.

## Возможности

- закрытая рабочая зона `/workspace` и авторизация без публичной регистрации;
- карточка проекта и версионность основных текстов;
- акты, сцены, кадры, персонажи, места и реквизит;
- производственный чек-лист с количественными требованиями, автоматическим прогрессом и ручным подтверждением;
- приватная медиатека для фотографий, видео, аудио, документов, заметок и внешних ссылок;
- публикации, публичная главная страница и управляемый блок пожертвований;
- ИИ-помощник: Responses API для текста и GPT Image 2 для генерации и редактирования изображений;
- история ИИ-запросов, версии принятых текстов, учёт токенов, изображений и расходов;
- первоначальные данные, импортированные из папки `DOC`.

## Требования

- PHP 8.3 или новее с расширениями `pdo_mysql`, `mbstring`, `openssl`, `fileinfo`, `dom`, `xml`;
- Composer 2;
- MySQL 8;
- Node.js 20 или новее и npm.

## Установка

```bash
composer install
copy .env.example .env
php artisan key:generate
npm install
npm run build
```

На Linux/macOS вместо `copy` используйте `cp`.

Создайте базу и пользователя MySQL, затем заполните в `.env`:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=silent_companion
DB_USERNAME=silent_companion
DB_PASSWORD=сложный_пароль
```

Задайте данные первого пользователя. Пароль должен содержать не менее 10 символов:

```env
FIRST_USER_NAME="Продюсер проекта"
FIRST_USER_EMAIL=producer@example.com
FIRST_USER_PASSWORD=сложный_пароль
```

Создайте структуру базы и первоначальные данные:

```bash
php artisan migrate:fresh --seed
```

После первого входа пароль и данные участников можно изменить в разделе «Команда». Не используйте пример пароля в рабочей среде.

## Запуск

Для разработки запустите в отдельных терминалах:

```bash
php artisan serve
php artisan queue:work --tries=2 --timeout=360
npm run dev
```

Публичная страница доступна по `/`, вход — по `/login`, рабочая зона — по `/workspace`.

В production веб-сервер должен направлять запросы только в каталог `public`. Также нужен постоянно работающий обработчик очереди, например под Supervisor или systemd.

## OpenAI

Ключ используется только Laravel-сервером и никогда не передаётся браузеру. Настройте в `.env`:

```env
OPENAI_API_KEY=
OPENAI_TEXT_MODEL=
OPENAI_IMAGE_MODEL=gpt-image-2
OPENAI_MONTHLY_BUDGET=0
OPENAI_USER_DAILY_LIMIT=20
```

`OPENAI_TEXT_MODEL` задаётся явно владельцем проекта. Значение `OPENAI_MONTHLY_BUDGET=0` отключает общий денежный предел; перед рабочим запуском рекомендуется установить ненулевой лимит. Тарифы зависят от модели и могут меняться, поэтому ставки для локального расчёта задаются переменными `OPENAI_TEXT_*_COST_PER_MILLION` и `OPENAI_IMAGE_COST_*`.

Изображения выполняются через очередь. Исходник при редактировании не перезаписывается: результат становится новым приватным материалом со связью с оригиналом.

## Файлы и приватность

Материалы сохраняются через Laravel Storage на диске из `ASSET_DISK` и по умолчанию приватны. Контроллер выдаёт внутренние файлы только активным авторизованным пользователям. Публичный доступ появляется исключительно после ручной публикации или явного выбора афиши/QR-кода в закрытых настройках.

Для S3-совместимого хранилища настройте диск Laravel и укажите его имя в `ASSET_DISK`; прикладную логику менять не требуется. Максимальный размер загрузки задаётся `MAX_UPLOAD_KB`. Для очень больших видео предусмотрена внешняя ссылка вместо передачи файла через PHP.

## Резервное копирование

В резервную копию должны одновременно входить:

- дамп MySQL (`mysqldump`);
- содержимое приватного диска, по умолчанию `storage/app/private`;
- папка `DOC` с исходными документами.

Не включайте `.env` в архивы, доступные посторонним. Периодически проверяйте восстановление базы и файлов на отдельном окружении.

## Проверки

```bash
php artisan test
php artisan view:cache
npm run build
```

Тесты используют SQLite в памяти и не затрагивают рабочую MySQL. Для окончательной проверки развертывания выполните `php artisan migrate:fresh --seed` на пустой тестовой базе MySQL.

В репозитории есть `php-local.ini` для локального Windows-окружения, где нужные расширения PHP установлены, но не включены глобально:

```powershell
$env:PHPRC=(Resolve-Path '.\php-local.ini').Path
php artisan test
```
